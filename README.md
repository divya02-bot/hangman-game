# Hangman Game

## Project Description
Hangman is a word-guessing game developed
using Python.

The player guesses a secret word one letter
at a time within a limited number of attempts.

## Technologies Used
- Python
- Random module

## Features
- Random word selection
- Letter guessing
- Limited wrong attempts
- Win and lose messages

## How to Run
1. Install Python.
2. Download the project.
3. Open the project folder.
4. Run hangman.py.
